# Quantum-Random-Number-Generator
A hardware-based random number generation system using avalanche noise from a reverse-biased Zener diode to generate unpredictable entropy for secure embedded applications.
# Overview
Software PRNGs are deterministic and depend on an initial seed. Your project investigates generating entropy from a physical stochastic process, using avalanche noise from a reverse-biased Zener diode. Your report explicitly identifies predictability and seed dependency as the motivation for moving toward physical randomness.
